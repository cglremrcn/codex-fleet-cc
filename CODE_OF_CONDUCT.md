# Code of Conduct

This project is maintained in public. Be direct about the work and considerate toward the people
doing it.

## Expected

- Critique behavior, code and evidence rather than a person's ability or intent.
- Reproduce a claim before escalating its severity.
- Credit prior work and preserve license obligations.
- Keep private data, credentials and unpublished vulnerabilities out of public threads.
- Make space for contributors with different languages, backgrounds and experience levels.
- Accept a clear technical disagreement without turning it into a personal dispute.

## Not accepted

- Harassment, threats, discrimination or sexualized attention.
- Doxxing or publishing private communication without permission.
- Deliberately misleading security claims, fabricated evidence or impersonation.
- Repeated disruption after a maintainer has set a reasonable boundary.
- Using project channels to pressure someone into an unrelated commercial or personal exchange.

## Enforcement

Maintainers may edit or remove content, close interactions, temporarily restrict participation or
ban a participant. Decisions should be proportional, documented privately and applied consistently.

Report conduct concerns privately to the repository owner through their GitHub profile. Do not use
a public issue when doing so would expose the affected person. Good-faith reports will not be
retaliated against.

This policy applies in repository spaces and when someone publicly represents the project.
