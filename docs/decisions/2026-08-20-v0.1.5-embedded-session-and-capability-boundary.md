# Fleet v0.1.5 embedded session and capability boundary

## Decision

Fleet Console embeds the selected Codex app-server thread instead of starting a nested `codex` CLI.
`thread/read` supplies a redacted transcript, `turn/steer` messages an active owned turn, and terminal
turns continue on the same thread. `Ctrl+G` closes the embedded session back to Fleet.

Terminal lane records are immutable admission identities. A duplicate lane ID is rejected before any
batch lane starts, a rejected continuation restores the prior terminal record, and every accepted lane
persists `admissionId`, `admissionSource`, and `admittedAt`. These fields identify the local Fleet
admission; they do not claim an authenticated human caller identity.

## Evidence and rejected hypotheses

- The original “Enter should need a nested CLI” hypothesis was wrong. The installed app-server protocol
  exposes both `thread/read` and `turn/steer`, so a second CLI process would weaken ownership and session
  continuity.
- A failed same-ID continuation previously replaced `complete` metadata with `failed`. Scheduler and live
  supervisor regression tests now prove the old terminal status, message, turn, and finish time survive.
- Model and effort strings are admitted only from the maintained compatibility matrix; all contract issues
  are still returned in one response.
- A real read-only Fleet lane on this Windows host saw the built-in image-generation tool but no callable
  Browser, Chrome control, Computer Use, `node_repl`, Chrome DevTools, or Playwright tool. The latter names
  appearing in config or skill metadata therefore remain `configured`, not `smoke_passed`.

## Privacy boundary

The embedded transcript omits reasoning and hook prompts. Command lifecycle may be shown, but command text
and raw command output are not rendered. Transcript content is read on demand and is not added to Fleet's
persistent metadata state.

## Application rule

Before dispatch, inspect Fleet status/results and repository history for already completed work. Never
reuse a terminal lane ID. Desktop Browser/Chrome/Computer Use may be routed only when the exact callable
tool is visible in the target lane and a lane-local non-mutating smoke passes; do not silently substitute
another browser surface. GPT Image work retains its explicit confirmation and artifact-verification path.
