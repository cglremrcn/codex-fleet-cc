# Fleet v0.1.3 stabilization decision

**Status:** Accepted

**Date:** 2026-08-19

Fleet v0.1.3 fixes a class of drift between the documented lane contract, CLI admission, supervisor
defense, runtime diagnostics, and operator UI.

The CLI and supervisor now share one admission validator. Safe read-only contracts may omit
`confirmationRef` or set it to `null`; any filesystem write, image generation/edit, browser mutation,
database write, or external effect requires a non-empty reference. Priority is one of `high`, `normal`,
or `low`. Validation returns every discovered issue with a property path before contacting the
supervisor. The reusable rule is that documentation examples and both admission boundaries must consume
one canonical policy rather than reimplementing it.

Doctor cleanup remains graceful. Timed-out probes and broker stdio are closed or detached after bounded
waiting; the CLI does not force `process.exit`. An ownership refusal remains fail-closed and never kills
the process, but doctor now exposes an ephemeral safe reason, PID, identity comparison, and remediation.
It does not guess which application owns the process or persist command lines and private paths.

The initial motion hypothesis was wrong: the renderer clock worked, but `COMPLETE` was intentionally
frozen while the header still said `MOTION LIVE`. The product decision is now to animate `COMPLETE`
subtly while independent verification is pending, lock `VERIFIED` and attention states, label the control
`ENABLED` or `PAUSED`, and show immediate text feedback. Wide and compact layouts expose actual panel
focus; one-lane navigation and non-cancellable terminal lanes explain why an action had no effect.

Claude may operate Fleet through start, status, result, follow-up, and exact cancellation preview. If a
Codex worker returns `complete` without the required artifact and asks only for redundant approval already
covered by the immutable contract, Claude may continue the same Codex thread at most twice. New scope,
authority, external effects, or a real user choice still stop for confirmation.

Visual lanes use Codex's built-in `$imagegen` route with explicit `image.generate` or `image.edit`
authority. The lane contract names GPT Image 2, preserves edit sources by default, copies the selected
artifact from `generated_images` into the approved workspace, verifies its file type and dimensions, and
returns a project-relative evidence path. Silent provider or API-key substitution is forbidden.
