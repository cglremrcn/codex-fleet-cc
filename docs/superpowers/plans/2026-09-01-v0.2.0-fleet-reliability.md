# Fleet v0.2.0 Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release Fleet v0.2.0 so Claude Code can orchestrate Codex lanes without losing valid controller requests, blindly redispatching timed-out admissions, hiding active lanes, or misreporting interrupted work.

**Architecture:** Keep Claude as controller, Fleet as the deterministic admission/lifecycle boundary, and Codex lanes as bounded workers. Repair the result and admission protocols first, propagate exact app-server authority second, then make the CLI/TUI expose the durable truth. Production release remains blocked until local, live-account, cross-platform CI, package, and installed-runtime parity gates pass.

**Tech Stack:** Node.js 22.20+ ESM, Node built-in test runner, Codex app-server JSON-RPC, local authenticated supervisor sockets, Claude Code plugin/marketplace tooling, GitHub Actions, `node-pty` 1.1.0.

**Spec:** `docs/specs/2026-09-01-v0.2.0-fleet-reliability-design.md`

## Global Constraints

- Release version is exactly `0.2.0` across package, plugin, marketplace, broker, archive defaults, setup ownership, docs, and generated artifacts.
- Claude Code validation pin becomes exactly `2.1.252` only after its local smoke passes.
- Codex CLI live-smoke target is exactly `0.151.0`; record the actual executable version in evidence.
- `node-pty` remains exactly `1.1.0`; add no production npm dependency.
- Imported `openai/codex-plugin-cc` files remain at tag `v1.0.6`, commit `db52e28f4d9ded852ab3942cea316258ae4ef346`.
- Preserve `additionalProperties: false`, fail-closed external-effect handling, one-writer scheduling, exact confirmation, immutable terminal records, and process ownership.
- Never persist raw prompts, reasoning, command output, cookies, credentials, or secrets.
- Never use `process/spawn` as an unsandboxed build workaround.
- Do not tag, publish, or claim release completion while any required gate is red or unexercised.
- Use conventional English commit messages with no Codex or agent attribution.
